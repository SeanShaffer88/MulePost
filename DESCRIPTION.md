# MulePost — Store listing description

**Your bags, routed. Your gold, never.**

Teach MulePost your alts once — cloth to the tailor, herbs to the alchemist, ore to the miner, greys to the bank alt — then every mailbox visit is two clicks: **Route my bags**, glance at the plan, **Send**.

The plan shows every mail before it exists: recipient, stacks, estimated postage, what's inside — each removable with one click. Postage totals come with a guard you set. Sending is deliberately unhurried: one mail at a time, each confirmed by the game before the next is touched, and any failure stops everything with the rest still safely in your bags.

Two promises are built into the code, not the settings page. **Nothing sends without the review screen and your press** — there is no auto-send. And **gold can never be attached**, because the addon contains no code path capable of attaching it; the build literally fails if one appears. Quest items are never routed, and anything the client hasn't identified yet is skipped and counted, never guessed.

Free, open source (MIT), no libraries. Forever only (interface 16001).

*Pre-launch note: v0.1.0 is built and locally verified against a mocked API; the live mailbox test happens after the November 4, 2026 launch.*
